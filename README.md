# lunch_menu_solomon

점심 메뉴 정하기가 힘들어서 후보군을 추리려고 만든 식당 정보 및 리뷰 사이트입니다.

## 기술 스택
- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Features**:
  - 식당 CRUD (등록, 조회, 수정, 삭제)
  - 식당별 별점, 작성자 이름, 리뷰 자유 작성 및 관리 (로그인 불필요)
  - 카테고리 필터링, 검색, 별점/리뷰수/이름 정렬 기능
  - 반응형 UI/UX 디자인

## 실행 방법
```bash
npm install
npm run dev
```

## 빌드 및 검사
```bash
npm run build
npm run lint
```
