# lunch_menu_solomon

사무실 주변 식당을 지도에서 찾고, 동료들의 추천과 리뷰로 점심을 고르는 팀 맛집 모음집입니다.

## 기술 스택
- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS + shadcn/ui (Radix primitives, lucide icons, Sonner toasts)
- **Features**:
  - 식당 CRUD (등록, 조회, 수정, 삭제)
  - 식당별 별점, 작성자 이름, 리뷰 자유 작성 및 관리 (로그인 불필요)
  - 카테고리 필터링, 검색, 별점/리뷰수/이름 정렬 기능
  - 반응형 UI/UX 디자인
  - 카카오 지도와 식당 목록에 동일한 검색·카테고리 필터 적용
  - 지도에서 식당 선택 시 상세 정보 및 팀 리뷰 표시
  - `/settings`에서 팀 이름과 사무실 주소 설정

## 코드 구조

자세한 규칙은 [SKILLS.md](./SKILLS.md)를 참고하세요.

- `src/components/ui` — shadcn/ui 컴포넌트, `src/components` — 화면 컴포넌트
- `src/hooks` — 페이지·컴포넌트 로직을 담은 커스텀 훅
- `src/services` — 브라우저 API(fetch, 카카오 지도 SDK, 알림) 호출 계층
- `src/server` — 서버 전용 로직 (`services` 비즈니스 규칙, `repositories` 데이터 접근, `db` 클라이언트)
- `src/app/api` — 요청/응답 변환만 하는 얇은 라우트 핸들러

## 카카오 지도 연결

1. [카카오 지도 공식 가이드](https://apis.map.kakao.com/web/guide/)에 따라 앱을 만들고 JavaScript 키를 준비합니다.
2. 카카오 개발자 콘솔에서 사용하는 JavaScript 키의 SDK 도메인에 `http://localhost:3000`과 실제 배포 주소를 등록합니다. 앱에서 지도 사용 설정이 필요한 경우 함께 활성화합니다.
3. `.env.local`에 아래 값을 넣고 개발 서버를 재시작합니다. 배포 시에는 빌드 전에 환경변수를 등록합니다.

```dotenv
NEXT_PUBLIC_KAKAO_MAP_CLIENT_KEY=발급받은_JavaScript_키
```

JavaScript 키는 브라우저에서 사용됩니다. REST API 키나 관리자 키를 넣지 마세요. 키가 없거나 SDK를 불러오지 못해도 목록·리뷰·카카오맵 검색 링크는 사용할 수 있습니다.

사무실 **장소 검색**은 서버에서 카카오 `GET /v2/local/search/keyword.json`을 호출합니다. `.env` 또는 `.env.local`에 `KAKAO_REST_API_KEY=발급받은_REST_API_키`를 추가하세요. 이 키는 서버에서만 사용합니다. 설정에서 키워드를 입력하고 **장소 검색** 버튼을 누르면 입력란 아래에 장소명과 주소를 정확도순으로 보여주고, 이전·다음 페이지를 조회할 수 있습니다. 입력 중에는 검색 API를 호출하지 않습니다. 목록에서 하나를 고르면 임시 선택 상태가 됩니다. **설정 저장**을 눌러야 장소 ID·이름·주소·좌표가 저장되고 홈으로 이동합니다. 저장하지 않고 나가면 기존 설정이 유지됩니다. 저장 실패 시에는 선택 상태를 유지해 다시 저장할 수 있습니다.

상단 **식당 등록**에서 이름을 입력하고 **장소 검색**을 누르면 카카오 검색 후보를 15개씩 조회할 수 있습니다. 이전·다음 페이지에서 식당을 선택하면 이름·주소·전화번호·분류가 자동으로 채워집니다. 필요한 정보를 보완한 뒤 **식당 등록하기**를 누르면 저장됩니다. 선택한 장소 ID와 좌표도 저장하므로 지도에 표시할 때 주소 변환을 다시 요청하지 않습니다.

상단 **설정**에서 팀 이름과 사무실 위치를 저장합니다. 사무실 주소가 없으면 식당 위치를 기준으로 지도를 표시합니다. 좌표가 없는 기존 식당은 등록된 주소를 변환해 표시하며, 주소를 찾지 못한 식당은 목록에만 남습니다. 기본 식당 데이터는 데모이므로 실제 식당명과 주소로 바꿔 사용하세요.

## 팀 설정과 데이터 저장

현재는 설치 하나를 한 팀이 공유하는 구조입니다. 팀 설정은 `data/team-settings.json`, 식당과 리뷰는 `data/restaurants.json`에 저장됩니다. 로그인과 팀별 접근 제어는 없으므로 앱에 접근하는 사용자는 설정을 변경할 수 있습니다. 파일이 유지되는 단일 서버 환경을 전제로 하며, 다중 서버나 임시 파일 시스템을 쓰는 배포 환경에서는 공유 데이터베이스로 전환해야 합니다. Supabase 패키지는 설치되어 있으나 데이터 저장에 연결되어 있지 않습니다.
